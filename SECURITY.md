# Sicurezza

Se trovi una falla (per esempio un modo per falsificare la firma di un percorso o per leggere la
posizione di qualcuno), **non aprire una issue pubblica**: usa "Report a vulnerability" nella scheda
Security di questo repository. Rispondiamo il prima possibile.

*English:* please report vulnerabilities privately via "Report a vulnerability" in the Security tab,
not in public issues.
